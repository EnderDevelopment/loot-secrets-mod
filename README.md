# Loot Secrets Mod

Adds new structures with loot secrets and small enemies to Minecraft

## Features

- Adds new structures with loot secrets
- Includes small enemies for combat encounters

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.14.0 or higher
- Java 17 or higher

## Installation

1. Download the mod from the releases page
2. Place the mod file in your `mods` folder
3. Launch Minecraft with Fabric

## Usage

Once installed, the mod will automatically add new structures and enemies to your world. Explore to discover the new loot secrets!
